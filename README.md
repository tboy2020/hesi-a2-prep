# Mubarak's HESI A2

An installable, offline practice app for the **HESI A2** nursing-admission exam —
176 original practice questions with explanations, study notes for every subject,
and a 6-week study plan.

**Open it:** https://tboy2020.github.io/hesi-a2-prep/

Add it to your phone's home screen to use it like an app, even offline.
